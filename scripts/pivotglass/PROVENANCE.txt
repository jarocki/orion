What it is: "AI-augmented framework for hunting, pivoting, and discovering
adversary infrastructure, indicators, and TTPs." Browser cockpit or terminal
deck; a workspace/evidence/provenance model with a relationship graph, 14
optional intelligence modules (API keys), STIX 2 export, and a complete
OFFLINE learning investigation (`workspace learn first-case`) that needs no key,
model, account or network — the natural first run on an air-gapped deck.

How it is wired in:
  ap (this dir)           launcher → /usr/bin/ap and /usr/bin/pivotglass (0700)
  Orion menu              "Pivotglass" .desktop → `ap web` (local browser UI)
  ~/.ap/                  per-session state (live system: not persisted)
  Nebula                  NOT yet exposed as MCP tools (issue #90 asks for
                          "hunts as MCP tools"; Pivotglass is workspace/DB-driven,
                          so that needs a designed read-only surface — follow-up).

127.0.0.1:8765 and created ~/.ap/workspaces.
