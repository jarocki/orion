What it is: "Reverse-engineer threat-actor tool and CLI choices from observed
Nuclei traffic." Builds a URL→template lookup table from the nuclei-templates
repo, attributes observed URLs to templates (with a quality grade), emits
per-tier Snort/Suricata + Sigma rules, and produces portable actor-behaviour
fingerprints that can be compared/matched across incidents.

How it is wired in:
  nucleotide-cli            launcher (PYTHONPATH here; python3 -m nucleotide)
                            → /usr/bin/nucleotide via the 0700 SCRIPT_MAP
  orionx-nucleotide-watch   URLs → lookup → Orion-X event bus (R.A.I.N. + Cockpit)
  /opt/orionx/nucleotide/   lookup.json + snort/ rules built at ISO-build time by
                            0520-nucleotide-lookup.hook.chroot (soft-fail; the
                            100 MB template clone is NOT shipped)
  Nebula MCP tools          nucleotide_lookup, nucleotide_fingerprint
