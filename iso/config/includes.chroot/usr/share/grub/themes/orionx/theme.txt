# Orion-X Phoenix Edition — GRUB theme
#
# @decision DEC-PHASE11-010
# @title W11-9a: GRUB orionx theme — Phoenix wallpaper backdrop + Phoenix-red accent
# @status accepted
# @rationale W11-9a GRUB theme: visual identity layer for UEFI boot menu.
#   Background is the W9-1 Phoenix wallpaper (operator-directed reuse,
#   2026-07-13 directive). Menu uses Phoenix-red (#E84000) for selected item.
#   Font: ONLY the two DejaVu faces live-build ships as .pf2 may be used —
#   "DejaVu Sans Bold 16" (dejavu-bold-16.pf2) and "DejaVu Sans Bold 14"
#   (dejavu-bold-14.pf2). Regular variants and Bold 18 are NOT in the ISO;
#   referencing them made gfxmenu fall back to the plain text menu
#   (DEC-PHASE11-041). grub.cfg loadfonts these before `set theme`. If richer
#   typography is wanted later, generate the .pf2 with grub-mkfont in the binary
#   stage and stage it alongside background.png, then point fonts here at it.
#
# ACTIVATION: ACTIVE. generate_bootloader_configs() (scripts/build-iso.sh) emits
# `set gfxmode=1024x768 / insmod png / set theme=…/theme.txt` (DEC-PHASE11-013),
# and DEC-PHASE11-040 bumps the menu timeout to 5s so the operator actually sees
# this screen. The background is a 1024x768 fit of the wide Phoenix wallpaper
# (no distortion) with a darkened center band for boot-menu legibility.
#
# Color palette:
#   Phoenix red    #E84000  → grub color: #e84000
#   Phoenix orange #FF6B00  → grub color: #ff6b00
#   Dark bg        #0A0A0F  → grub color: #0a0a0f
#   White text     #F0F0F0  → grub color: #f0f0f0
#   Gray inactive  #606060  → grub color: #606060
